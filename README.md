## 📦 Required Libraries

이 프로그램을 실행하려면 **Python 3**가 설치되어 있어야 합니다.

### 사용 라이브러리

| 라이브러리 | 설치 필요 여부 | 용도 |
|---|---:|---|
| `opencv-python` | ✅ | 웹캠/IP 카메라 연결 및 영상 처리 |
| `numpy` | ✅ | 배열 연산 및 히스토그램 처리 |
| `Pillow` | ✅ | OpenCV 영상을 Tkinter에 표시 |
| `ultralytics` | ✅ | YOLOv8 객체 탐지 |
| `tkinter` | 기본 포함 | GUI 제작 |
